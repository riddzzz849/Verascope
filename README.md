# Verascope

### Evidence-Based Information Verification Platform

**Author:** Riddhima Utreja

Verascope is an evidence-based verification platform designed to help users assess the reliability of information found online. It analyzes claims against credible and authoritative sources and provides transparent, source-linked assessments so users can see the evidence for themselves.

> **Don't just trust the information. Verify the evidence.**

---

## About Verascope

In today's digital world, information spreads rapidly through social media, messaging platforms, websites, and online communities. However, determining whether a claim is accurate, misleading, outdated, or unsupported can be difficult.

Verascope addresses this problem by providing a structured way to examine claims and identify the evidence behind them.

The platform focuses on:

* Claim verification
* Credible source discovery
* Source-linked evidence
* Transparent verification results
* Verification date and freshness
* Identification of potentially misleading information
* Clear explanations instead of simply labeling information as "true" or "false"

---

## Key Features

### Claim Verification

Enter a claim, statement, or piece of information and analyze it against available credible sources.

### Evidence-Based Results

Verascope presents supporting or contradicting evidence from relevant sources rather than providing an unexplained verdict.

### Source Transparency

Every assessment is linked to its underlying source whenever available, allowing users to independently inspect the evidence.

### Reliability Assessment

Claims can be categorized based on the available evidence:

* Supported
* Partially Supported
* Contradicted
* Insufficient Evidence

### Source Quality

The platform considers the reliability and authority of the sources used to assess a claim.

### Verification Timestamp

Users can see when the information was last checked, helping identify potentially outdated claims.

### Reliability Report

Each verification can provide a structured report containing:

| Field           | Description                                       |
| --------------- | ------------------------------------------------- |
| Claim           | The information being investigated                |
| Assessment      | Overall verification result                       |
| Source Quality  | Reliability of the sources used                   |
| Evidence        | Information supporting or contradicting the claim |
| Official Source | Relevant authoritative source, if available       |
| Last Verified   | Date and time of verification                     |
| Source Links    | Direct links to supporting evidence               |

## Problem Statement

The internet makes information accessible faster than ever, but accessibility does not guarantee reliability.

Users frequently encounter claims through:

* WhatsApp
* Instagram
* Telegram
* Social media
* News websites
* Blogs
* Online communities
* Search results

Many users do not have the time or resources to independently investigate every claim they encounter.

**Verascope aims to make evidence-based verification easier, more transparent, and accessible.**

## How Verascope Works

```text
User enters a claim
        |
        v
Claim is analyzed
        |
        v
Relevant credible sources are identified
        |
        v
Evidence is compared with the claim
        |
        v
Source quality is assessed
        |
        v
Verification result is generated
        |
        v
Evidence and source links are displayed
```

The goal is not simply to tell users what to believe.

The goal is to **show users why a claim receives its assessment.**

## Example

### User Claim

> "A particular government scheme provides free benefits to every citizen."

### Verascope Analysis

**Assessment:** Partially Supported

**Evidence Found:**
The official government source confirms that the scheme exists, but eligibility requirements apply.

**Source Quality:** High

**Official Source:** Available

**Last Verified:** Current verification date

**Conclusion:**
The original statement is misleading because the benefit is not available to every citizen.

## Design Philosophy

Verascope follows a clean, modern, and trustworthy interface.

The design emphasizes:

* Minimal clutter
* Clear verification results
* Evidence visibility
* Source transparency
* Responsive layouts
* Accessible typography
* Visual distinction between supporting and contradicting evidence
* Light and dark mode support

The interface is designed to communicate **trust and transparency rather than sensationalism**.

---

## Important Principle

Verascope is designed to assist users in evaluating information. A verification result should not be treated as an unquestionable authority.

Sources, evidence, publication dates, and context should remain visible so that users can make informed judgments themselves.

**Verascope doesn't ask users to blindly trust the platform. It helps them inspect the evidence.**

## Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/verascope.git
```

### 2. Navigate to the Project

```bash
cd verascope
```

### 3. Install Dependencies

Install the dependencies required by the selected frontend and backend technologies.

### 4. Configure Environment Variables

Create a `.env` file and add the required API keys, database credentials, and configuration values.

```env
API_KEY=your_api_key
DATABASE_URL=your_database_url
```

Start the frontend and backend according to the project's implementation.

## Disclaimer

Verascope is an information verification and research-assistance platform.

Users are encouraged to review the linked evidence and make their own informed decisions.
